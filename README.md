
# TJM Project - Grounding Agent

Vision-based desktop automation with icon and text grounding. Locates notepad desktop icon via
grounder + ReGround method (See DESIGN.md), regardless of the icon position and automates fetcing posts into notepad .txt files.

## Setup
```
uv sync
```

## Run
```
uv run main.py
```
See [DESIGN.md](./DESIGN.md) for architecture, grounding strategy and tradeoffs
